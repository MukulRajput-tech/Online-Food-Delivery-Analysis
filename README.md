# Online Food Delivery Analysis - Comprehensive Data Analytics Project

## 📊 Project Overview

**Version: 2.0 - Completely Redesigned**

This is a comprehensive **Exploratory Data Analysis (EDA)** project analyzing 388 online food delivery customers across 13 demographic and behavioral attributes. The analysis is part of the **IBM SkillsBuild Data Analytics with AI Academic Internship Program** (AICTE, BharatCares).

**NO Machine Learning | PURE EDA | 50+ Insights | 12 Recommendations**

---

## 🎯 Problem Statement

Analyze online food delivery customer data to:
1. Understand comprehensive customer demographics and segmentation
2. Analyze customer behavior patterns and loyalty trends
3. Identify geographic hotspots and expansion opportunities
4. Evaluate customer satisfaction levels and feedback
5. Generate actionable business strategies and recommendations

## 📦 Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)
- Jupyter Notebook/Lab
- ~200MB disk space

### Step-by-Step Installation

**1. Create Project Directory**
```bash
mkdir online-food-delivery-analysis
cd online-food-delivery-analysis
```

**2. Create Virtual Environment (Recommended)**
```bash
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (macOS/Linux)
source venv/bin/activate
```

**3. Install Dependencies**
```bash
pip install -r requirements.txt
```

**4. Launch Jupyter**
```bash
jupyter notebook
# OR
jupyter lab
```

**5. Open Notebook**
- Open `Mukul_Rajput_OnlineFoodDeliveryAnalysis_v2.ipynb`
- Ensure `online_food_delivery_dataset.csv` is in same directory

**6. Run Analysis**
- Execute cells in order
- All 15 sections will run sequentially
- Generates 16+ visualizations
